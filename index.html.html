關於本計劃

Project FLS_Elder 是一個關愛長者的科技創新計劃。我們運用最新的人工智能技術， 包括 TensorFlow.js、BlazeFace 人臉偵測、Google Teachable Machine 等， 開發簡單易用的輔助工具，幫助腦退化症患者維持與家人的連繫， 減輕照顧者的負擔，讓科技成為關愛的橋樑。

🧠 TensorFlow.js 👤 BlazeFace 🎓 Teachable Machine 🗣️ Web Speech API 📱 響應式設計 🍎 iOS 優化
